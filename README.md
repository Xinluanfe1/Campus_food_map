# 校园美食地图

以校园地图为核心、由用户共同贡献店铺数据，并通过评分评价与排行榜帮助用户发现校园美食的可配置平台。

- 默认示范校园：西南交通大学犀浦校区
- 第一阶段目标：完成本地可运行的网页版
- 后续目标：支持公网部署、小程序复用后端 API，以及其他校园的数据接入
- 开发模式：AI 辅助开发，人工决策与验收
