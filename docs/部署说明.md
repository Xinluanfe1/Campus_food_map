# 校园美食地图部署说明

本文档覆盖本地开发/调试部署与公网部署注意事项，与 README 配合使用。

## 一、环境要求

| 依赖 | 版本要求 | 说明 |
| --- | --- | --- |
| Python | 3.12 及以上（开发环境 3.14.7） | 后端运行与脚本 |
| Node.js | 20 及以上 LTS（开发环境 24.20.0） | 前端构建与开发服务器 |
| 浏览器 | 任意现代浏览器 | 支持 Leaflet 与百度地图 JSAPI |

不需要任何付费 API 或云服务即可完成本地核心功能测试；地图可选图片底图、瓦片地图（如 OpenStreetMap）或百度地图 JSAPI。

## 二、本地部署步骤

1. 获取代码（Git 克隆或复制项目目录）。
2. 安装后端依赖并准备数据库：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python -m app.db.init_db
```

3. 安装前端依赖：

```powershell
cd frontend
npm.cmd install
```

> Windows 提示「无法加载文件 npm.ps1，因为在此系统上禁止运行脚本」时，属于 PowerShell 执行策略限制，不是项目问题：
> 使用 `npm.cmd` 代替 `npm` 即可；也可以执行 `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`（仅对当前用户生效）后继续使用 `npm`。

4. 启动服务（两种方式任选）：

```powershell
# 方式一：项目根目录执行脚本，自动打开两个窗口
powershell -ExecutionPolicy Bypass -File scripts\start-all.ps1

# 方式二：手动分别启动
powershell -ExecutionPolicy Bypass -File scripts\start-backend.ps1
powershell -ExecutionPolicy Bypass -File scripts\start-frontend.ps1

# 方式三：不使用脚本，直接在两个窗口执行
cd backend; .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
cd frontend; npm.cmd run dev -- --host 127.0.0.1 --port 5173
```

5. 访问地址：

- 前端页面：<http://127.0.0.1:5173>
- 后端接口文档：<http://127.0.0.1:8000/docs>（生产环境自动关闭）
- 健康检查：<http://127.0.0.1:8000/api/v1/health>

## 三、环境变量说明（backend/.env）

| 变量 | 是否必填 | 说明 |
| --- | --- | --- |
| `APP_ENV` | 否 | `development`（默认）或 `production`；生产环境会关闭接口文档并要求 JWT 密钥 |
| `DEBUG` | 否 | 生产环境应设置为 `false` |
| `HOST`、`PORT` | 否 | 后端监听地址与端口，默认 `127.0.0.1:8000` |
| `CORS_ORIGINS` | 否 | 允许访问后端的前端地址，多个用英文逗号分隔 |
| `DATABASE_URL` | 否 | SQLite 数据库地址，默认 `sqlite:///../data/campus_food.db` |
| `UPLOAD_DIR`、`MAP_DIR` | 否 | 店铺照片与校园底图目录 |
| `JWT_SECRET` | 生产必填 | JWT 签名密钥；开发环境留空时使用临时密钥（重启后需重新登录） |
| `ADMIN_INITIAL_PASSWORD` | 否 | 初始化管理员密码；留空时初始化脚本生成随机密码并打印一次 |
| `BAIDU_MAP_AK` | 使用百度地图时必填 | 百度地图 JSAPI 密钥；只写入本地 `.env`，不得提交到代码仓库 |

`.env`、数据库文件、上传目录与备份文件均已加入 `.gitignore`，不会进入版本库。

## 四、地图提供方与百度地图 AK

校园配置中的 `map_provider` 决定真实地图的提供方：

- `tiles`（默认）：使用瓦片地址模板（如 OpenStreetMap），不依赖任何密钥。
- `baidu`：使用百度地图 JSAPI（BMapGL）。此时：
  - `tile_url_template` 存放百度 JSAPI SDK 地址，例如 `https://api.map.baidu.com/api?type=webgl&v=1.0`（不含 AK）；
  - AK 通过后端环境变量 `BAIDU_MAP_AK` 提供，接口 `/api/v1/campuses/{campus_id}/map` 会在该校园使用百度提供方时把 AK 下发给前端；
  - 前端不会在代码里写死 AK，仓库中也不保存 AK；
  - 必须在百度地图开放平台为该 AK 配置 Referer 白名单（本地调试可用 `*`，上线前必须改为具体域名）。

启用百度提供方的示例校园配置：

```json
{
  "campus_id": "swjtu_xipu",
  "campus_name": "西南交通大学犀浦校区",
  "map_type": "real",
  "map_provider": "baidu",
  "map_asset_url": null,
  "tile_url_template": "https://api.map.baidu.com/api?type=webgl&v=1.0",
  "map_attribution": "百度地图",
  "allow_off_campus": true,
  "default_latitude": 30.7558,
  "default_longitude": 103.9922,
  "default_zoom": 16,
  "boundary_radius_meters": 2500,
  "is_active": true
}
```

导入命令：`python -m app.db.import_campuses`。百度地图使用 BD09 坐标，请确保该校园的店铺坐标同样是 BD09，避免坐标偏移。

## 五、运维脚本

```powershell
# 备份（数据库 + 底图 + 照片 + 校园配置）
python -m app.db.backup

# 恢复（覆盖前自动生成安全副本；--dry-run 只校验）
python -m app.db.restore --input ..\backups\campus_food_backup_xxx.zip

# 数据一致性检查（外键、孤立记录、坐标体系、审核记录）
python -m app.db.check_consistency

# 重复执行安全的数据库初始化
python -m app.db.init_db
```

## 六、公网部署注意事项

1. **免费托管平台的限制**：多数免费平台使用临时文件系统，重启可能丢失 SQLite 数据库与上传图片；部署前必须确认磁盘持久化能力，或改为挂载外部存储，否则需要每次重新初始化数据。
2. **数据库与并发**：第一阶段使用 SQLite，适合单实例、小规模使用；不要承诺高并发写入，也不要同时部署多个后端实例写同一个库。
3. **地图服务政策**：公共瓦片服务（如 OpenStreetMap）与百度地图免费额度都有使用条款、署名要求与流量限制；上线前必须核对当前政策，流量较大时改用自托管资源或购买合规服务。
4. **密钥与调试开关**：生产环境必须设置 `JWT_SECRET`、`APP_ENV=production`、`DEBUG=false`，并关闭接口文档；百度 AK 必须配置 Referer 白名单。
5. **HTTPS 与 Cookie**：公网使用 HTTPS 时把 `COOKIE_SECURE` 设为 `true`；前端与后端建议同源部署，或正确配置 `CORS_ORIGINS`。
6. **数据备份**：上线后定期执行 `python -m app.db.backup` 并把备份文件保存到项目目录之外。
7. **不需要修改业务代码**：更换校园、底图、地图提供方都通过配置完成，公网部署不应要求改动前端或后端业务逻辑。
